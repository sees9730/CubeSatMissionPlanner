=======================
CubeSat Mission Planner
=======================

Welcome to the CubeSat Mission Planner documentation. This tool helps you design, simulate, and analyze missions for CubeSat platforms.

Features
========

* Mission configuration through Excel templates
* Satellite position and orbit visualization
* Target visibility analysis
* Eclipse prediction and planning
* Operational scheduling
* Power and data budget management
